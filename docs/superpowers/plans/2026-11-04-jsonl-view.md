# jsonl-view Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A read-only native macOS viewer for `.jsonl` files, with a Quick Look preview, that renders Claude Code transcripts as a live-updating conversation and arranges any other `.jsonl` sensibly.

**Architecture:** All parsing and modeling lives in a local Swift package, `JSONLCore`, tested with `swift test` and no UI. Two Xcode targets, generated by XcodeGen from `project.yml`, depend on it: the `JSONLView` SwiftUI app and the `JSONLPreview` Quick Look preview extension. A shared summary service (Foundation Models, behind a protocol) and a file cache in an App Group serve both targets.

**Tech Stack:** Swift 6.4, SwiftUI, Swift Testing, XcodeGen, QuickLookUI (`QLPreviewingController`), FoundationModels, Dispatch file sources. Xcode 27.1, macOS 27.2.

**Spec:** `docs/superpowers/specs/2026-11-04-jsonl-view-design.md`

## Global Constraints

- Read-only: no code path opens a viewed file for writing.
- No network use in either target. No entitlement for outgoing connections.
- Summary generated on device only, via Apple FoundationModels. No other model.
- macOS deployment target 27.0. Swift 6 language mode.
- Signing team `997DW79YCR` ("Apple Development: John Brahy"). Bundle IDs `com.brahy.jsonl-view` and `com.brahy.jsonl-view.preview`.
- App Group `997DW79YCR.com.brahy.jsonl-view` (summary cache).
- File type: imported UTI `org.jsonlines.jsonl`, extension `jsonl`, conforms to `public.data` and `public.text`. The system has no UTI for `.jsonl` (it shows a `dyn.` type), so this declaration is required.
- Install target `/Applications/JSONLView.app`.
- Test fixtures are synthetic. Never copy a real transcript from `~/.claude` into the repo (they contain secrets).
- No em dashes and no emojis in UI copy or docs.

## Review Focus

1. **Huge files (about 50 MB, 30k lines):** the window must show the first screen in under 2 s and stay scrollable; Quick Look must not time out. Tests: `testParses50MBWithin3s` (Task 2), `testPreviewFactsCapped` (Task 9).
2. **A single enormous line (a 5 MB tool result):** folded rows must not lay out the full text; expanded results truncate to 20,000 characters with a "Show all" button. Test: `testToolResultPreviewTruncates` (Task 2).
3. **Garbage in a `.jsonl` (non-JSON lines, binary, empty file, one huge non-JSON line):** shows what it can, counts bad lines, never crashes. Tests: `testSkipsInvalidLines`, `testEmptyFile` (Task 1), `testNonJSONFileIsGeneric` (Task 5).
4. **Foundation Models unavailable or input too long:** summary area shows "Summary unavailable: <reason>" in one line; everything else renders. Test: `testUnavailableSummarizerYieldsReason` (Task 7).
5. **`tool_result.content` as a list of blocks, including images, rather than a string:** text blocks join, image blocks render as "[image]". Test: `testToolResultBlockContent` (Task 2).

### Task 6: FileTailer for live sessions

### Task 7: Summary service and cache

**Files:**
- Create: `SummaryService.swift`
- Test: `SummaryServiceTests.swift`

**Interfaces:**
- Produces:
  - `protocol Summarizing: Sendable { func summarize(_ digest: String) async throws -> String }`
  - `struct FoundationModelsSummarizer: Summarizing`, built on `SystemLanguageModel.default` and `LanguageModelSession`, with these instructions: "Summarize this Claude Code session for its owner in 2 to 3 plain sentences: what was asked, what got done. End with 'Outcome: done', 'Outcome: partial' or 'Outcome: abandoned'. No em dashes."
  - `enum SummaryState: Equatable { case generating, ready(String), unavailable(String) }`
  - `struct CacheKey: Hashable { let path: String; let size: UInt64; let mtime: Date }`
  - `final class SummaryCache { init(directory: URL); func get(_ k: CacheKey) -> String?; func put(_ k: CacheKey, _ s: String) }`; one JSON file per key (SHA-256 of the path, size and mtime). Default directory: the App Group container's `Summaries/`.
  - `actor SummaryService { init(summarizer: Summarizing, cache: SummaryCache); func summary(for key: CacheKey, digest: @Sendable () -> String) async -> SummaryState }`

The unavailable reasons come from `SystemLanguageModel.default.availability`, phrased as "Apple Intelligence is off", "model not downloaded", "not supported here". A thrown error, including context overflow, becomes "Summary unavailable: <localized description>".

Behavior, matching the spec's "Main window" section:
- `DocumentGroup(viewing:)` or `WindowGroup(for: URL.self)` plus `onOpenURL`. Either way, no save or edit commands.
- The first 2 MB are parsed on the main actor, so the window paints fast. The rest is parsed in the background and appended. Then `FileTailer` starts from the final offset.
- Sidebar section "This folder": sibling `.jsonl` titles from `SessionFacts` built with a 256 KB head read, filled in lazily. Section "Outline": numbered prompts; clicking one scrolls to it with `ScrollViewReader`.
- Header card: title, plus the first sentence of the summary (or "Generating summary text...").
- Rows: user bubble on the right in blue, Claude on the left in grey, timestamps. Thinking and tool calls fold to one line in monospace (`Bash: <inputSummary>`) and expand to show the input JSON and `resultPreview`, with "Show all". An `Agent`/`Task` call with a matching `SubagentRef` shows an accent bar and "Subagent: <agentType> (N tool calls)", and expands into a nested `ConversationView`.
- When new items arrive and the view is scrolled to the bottom, it stays pinned to the bottom.
- Search field (Cmd-F): filters to matching items and highlights matches; Return goes to the next match.
- Generic files get `GenericView`: `Table` for `.table`, a `List` of `DisclosureGroup` pretty-printed records for `.records`, and an "N invalid lines skipped" banner when `invalidCount > 0`.

### Task 9: Quick Look preview

**Files:**
- Create: `Preview/PreviewView.swift`
- Modify: `Preview/PreviewViewController.swift`

**Interfaces:**
- Consumes: `LineReader` (with `maxBytes`), `SessionFacts`, `GenericModel.facts`, `SummaryCache` (read only)
- Produces: `PreviewViewController: NSViewController, QLPreviewingController` hosting `PreviewView` in an `NSHostingView`

Layout copied from the approved mockup (spec, "Quick Look preview"): title + format badge, path/branch/time line, Summary block, six fact tiles, First prompt, Last reply. Generic files: record count, invalid lines, top keys, 3 sample rows, same summary block. `preparePreviewOfFile(at:)` returns at once with a header; the facts fill in when parsed. Cap: files up to 64 MB are read in full. Above that, the first and last 8 MB are read and the tiles show "approx".
